## How each episode works

Every episode has its own folder with:
- **One notebook** that holds the slides and the code together, in the same order as the video
- **All outputs saved**, so you can read it without running anything
- An **Open in Colab** button, so you can run it free in your browser
- A **README** with a summary of what we found

## Run the code on your computer

```bash
pip install -r requirements.txt   # from the root of this repository
```

Then open any notebook in Jupyter or VS Code. Python 3.11 or 3.12 is recommended.
