## How to use these notebooks

- **Just reading?** Click a notebook link. GitHub shows it with all the code and explanations.
- **Want to practise?** Click **Open in Colab**. It runs in your browser for free, with nothing to install. Change the code, run it, and see what happens. That's the best way to learn.
- **Running locally?** Install Python 3, then `pip install jupyter` and open the notebook with `jupyter notebook`.

These lessons use only Python's standard library. No extra packages needed.
